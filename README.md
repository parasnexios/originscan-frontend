# originscan-frontend

Mobile-first consumer QR verification web application for **OriginScan**.

## Features
- Dynamic QR code parameter extraction (`/v/:code`)
- Responsive 3-box unit code verification with automatic focus shifting
- Full batch lookup toggle option
- Authentic verification celebration (confetti) and real-time backend API integration
- Clear consumer advisory notices for recalled, blocked, or not-found products
- Display customization integration (FSSAI licence, manufacturing date, expiry date, manufacturer address, support contact)

## Getting Started

```bash
npm install
npm run dev
```

Runs by default on `http://localhost:5173`.
